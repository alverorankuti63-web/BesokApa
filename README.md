# Besok Apa? Website

Cara menerbitkan lewat GitHub Pages di HP:
1. Unduh dan ekstrak ZIP ini.
2. Buka repo GitHub `BesokApa` milikmu.
3. Upload file **di dalam folder** ini (`index.html`, `style.css`, `app.js`, `manifest.json`, `README.md`) ke bagian utama/root repo, bukan folder induknya.
4. Buka **Settings → Pages**.
5. Di **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, lalu **Save**.
7. Tunggu beberapa menit, lalu buka alamat website yang ditampilkan di halaman Pages.

Jadwal disimpan di browser perangkat. Tombol notifikasi hanya mengirim notifikasi uji; website statis tidak bisa menjamin notifikasi otomatis pada waktu terjadwal ketika browser ditutup.
